# Тесты

Автотесты гоняют расширение в настоящем Chromium: открывают страницы, применяют стили, двигают ползунки в попапе и проверяют, что получилось.

## Запуск

```bash
cd tests
npm install        # один раз
npm test           # основной набор, ~2 минуты, интернет не нужен
```

Если Chromium для Playwright ещё не стоит: `npx playwright install chromium`.

Все прошли — в конце `Итого: N/N прошло`, код выхода 0. Если что-то упало, видно, что именно, и код выхода 1.

## Что ещё есть

- `npm run test:youtube` — проверка на настоящем Ютубе: размер шрифта и «Не трогать видео». Нужен интернет. Ютуб может поменять вёрстку, поэтому этот набор не входит в основной. Снимки экрана сохраняются в `tests/out/`.
- `HEADED=1 npm test` — показать браузер во время прогона.
- `CHROME_PATH=/путь/к/chrome npm test` — взять свой браузер.

## Устройство

- `run.mjs` — основной набор
- `youtube.mjs` — проверка на Ютубе
- `lib.mjs` — запуск браузера с расширением, локальный сервер, подсчёт результатов
- `pages/` — тестовые страницы: с iframe, плеером, картинками в `<picture>`, «живым» DOM и т.п.

Новый баг — сначала тест, который его ловит, потом починка.
