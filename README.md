# Расширение Цвет

Браузерное расширение (Chrome MV3) для Helium и других Chromium-браузеров: меняет цвета, шрифты и стиль страниц.

## Возможности

- **Тёмный / светлый режим** — принудительно, для сайтов без нормальной темы
- **Авто день/ночь** — галочка: после 19:00 сайты сами темнеют, после 7:00 светлеют
- **10 пресетов:** Инверсия, Сепия, Ч/Б, Синий, Матрица, Читаю, Comic Sans, Тёплая, Контраст
- **🎲 Рандом всего CSS** — каждый жмак случайные цвета, шрифт, тени, интервалы, иногда CAPS и скругления
- **Сохранение стилей** — понравился рандом? Введи имя и сохрани, стиль будет в «Мои стили»
- **Экспорт/импорт кодом** — у своего стиля жми ⇪, код скопируется; друг вставляет код в поле импорта и получает тот же дизайн
- **Медиа отдельно** — опция «Медиа»: фильтр только для видео и картинок (инверсия/сепия/ч/б/психоделика), независимо от стиля страницы; видеоплееры и их оверлеи больше не закрашиваются — Ютуб в тёмном режиме не блочится
- **Тонкая настройка** — ползунки: оттенок, насыщенность, яркость, размер шрифта; результат можно сохранить
- **Горячие клавиши** — `Alt+R` случайный стиль, `Alt+D` сброс (переназначить: `chrome://extensions/shortcuts`)
- **Правила по сайтам** — выбранный стиль запоминается для каждого сайта; список правил с удалением — в блоке «Сайты»
- **Удаление чего угодно** — красный ✕ у своих стилей и системных пресетов (кроме «Сброс»); удалённое не возвращается

## Установка одной командой

```bash
curl -fsSL https://git.lab.ai-hr.kz/APA-AI-LAB/POLEZNYI-MUSOR/raw/branch/main/install.sh | bash
```

Скрипт скачает расширение в `~/расширение-цвет`. Свой путь:

```bash
curl -fsSL https://git.lab.ai-hr.kz/APA-AI-LAB/POLEZNYI-MUSOR/raw/branch/main/install.sh | bash -s -- /свой/путь
```

Или просто скачать архив: [main.zip](https://git.lab.ai-hr.kz/APA-AI-LAB/POLEZNYI-MUSOR/archive/main.zip)

## Обновление одной командой

```bash
curl -fsSL https://git.lab.ai-hr.kz/APA-AI-LAB/POLEZNYI-MUSOR/raw/branch/main/update.sh | bash
```

Обновит расширение в `~/расширение-цвет` до последней версии с `main`. Свой путь: `... | bash -s -- /свой/путь`.

После обновления нажми «Обновить» на `chrome://extensions` (или перезапусти браузер).

## Установка руками

1. Скачай и распакуй репу
2. Открой `chrome://extensions`
3. Включи «Режим разработчика»
4. «Загрузить распакованное расширение» → выбери папку с `manifest.json`

## Примечания

- На служебных страницах браузера (`chrome://`, настройки) расширения не работают — ограничение Chromium
- Рандом каждый раз новый: жми кнопку сколько хочешь
- Авто день/ночь не трогает сайты, где ты выбрал стиль вручную — явный выбор всегда важнее
